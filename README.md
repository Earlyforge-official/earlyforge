# EarlyForge Trends API — clients

Official client libraries for the [EarlyForge Trends API](https://docs.earlyforge.ai/guides/api/trends-api): an authenticated Pulse mirror (free, any plan) plus a paid-plan full trends feed, under the same `/v1/api/trends/*` prefix.

Full documentation: **[docs.earlyforge.ai/guides/api](https://docs.earlyforge.ai/guides/api)**

Each package has its own README with install, quickstart, and the full method/command list.

## Getting an API key

Create a free account at [earlyforge.ai](https://earlyforge.ai), then generate a key from **Settings → API Keys**. Pulse access is free on every plan, no card required.
