# Contributing

Thanks for your interest in improving the EarlyForge client libraries.

## Reporting a bug or requesting a feature

Open an [issue](https://github.com/Earlyforge-official/earlyforge/issues) with:

- Which package (`sdk-python-earlyforge`, `sdk-js-earlyforge`, `sdk-php-earlyforge`, `cli-earlyforge`, or `mcp-earlyforge`)
- Steps to reproduce (for a bug) or the use case (for a feature)
- Package version and language runtime version

## Submitting a pull request

1. Fork the repo and create a branch from `main`.
2. Make your change in the relevant package directory only — each package is self-contained with its own tests.
3. Run that package's test suite before opening the PR (see its README for the exact command).
4. Open a PR against `main` with a clear description of what changed and why.

## Questions

For anything not covered here, email [support@earlyforge.ai](mailto:support@earlyforge.ai) or see the [full documentation](https://docs.earlyforge.ai/guides/api).
